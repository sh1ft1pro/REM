*Исходя из прошлой версии «Robot Emulator» (v4.0, октябрь 2024), приступаем к созданию новой версии Robot Emulator, в связи с тем, что пакеты, библиотеки и методы, используемые в прошлой версии очень упрощенные, устаревшие и неактуальные.*

## Ноябрь 2026 разработка

### Какие работы выполнены

1. Основная технологическая часть кода ядра написана.
2. Терминал функционирует верно и соединен с ядром.
3. Налажена "простая" связь между Arduino и PC (идет пинг).

### Какие работы необходимо выполнить

1. Сделать связь через MODBUS.
2. Корректировка интерфейса системы ("дерганое" движение робота, съехавшие картинки).
3. Написание функций отладки через консоль.

### Планы

1. Создание платы отправки (считывание, разбор принятых данных, координация данных).
2. Написание переводчика пройденного пути виртуального робота в код, понятный роботу.
3. Программирование актуаторов робота.
4. Программирование езды робота "по коду" пройденного виртуального пути.
5. Возможность "трансляции", управление, отладка роботом в "прямом эфире" с компьютера.
